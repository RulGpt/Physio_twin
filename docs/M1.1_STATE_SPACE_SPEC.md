# PHYSIO-TWIN M1.1 — State-Space Model Specification

## State
X_t = [F_t, R_t, L_t]^T

F = latent fatigue, R = latent recovery, L = latent physiological/routine load.

## Inputs
U_t = [D_t, E_t, S_t]^T

- D: sleep deficit relative to the selected/reference sleep duration
- E: exercise load = duration × intensity / 10
- S: normalized subjective stress = stress / 10

Habit load is intentionally excluded from M1 until a transparent, defensible feature definition is established.

## Observations
Y_t = [F_obs,t, R_obs,t]^T

F_obs = fatigue / 10
R_obs = recovery / 10

C = [[1,0,0],[0,1,0]]

Thus fatigue and recovery directly observe their corresponding latent states; load remains latent.

## Transition
X_(t+1) = A X_t + B U_t + w_t

A is 3×3 and B is 3×3. Their signs and magnitudes are parameters to estimate/validate from longitudinal data, not universal biological constants.

## Noise
w_t ~ N(0,Q)
v_t ~ N(0,R)

Q is state/process uncertainty. R is self-report/measurement uncertainty.

## Filtering
Prediction:
m^-_t = A m_(t-1) + B U_(t-1)
P^-_t = A P_(t-1) A^T + Q

Update on available observations:
e_t = y_t - C m^-_t
S_t = C P^-_t C^T + R
K_t = P^-_t C^T S_t^-1
m_t = m^-_t + K_t e_t

Use the Joseph covariance form:
P_t = (I-KC)P^-(I-KC)^T + K R K^T

Missing observations are represented by NaN and skipped rather than imputed inside the filter.

## Forecast
For known/planned future inputs:
m_(t+k|t) = A m_(t+k-1|t) + B U_(t+k-1)
P_(t+k|t) = A P_(t+k-1|t) A^T + Q

## Stability
Check spectral radius rho(A) = max |lambda_i(A)|.
The initial linear model requires rho(A) < 1.

This is a mathematical stability constraint, not a biological claim.

## Estimation
Fit population parameters first. Then evaluate personal baseline normalization and partial parameter adaptation only when longitudinal data support it.

Statsmodels provides state-space/Kalman filtering and MLEModel provides maximum-likelihood parameter fitting. The PHYSIO-TWIN mathematical layer remains explicit in project code for auditability.

## Validation
Use chronological longitudinal splits. Report MAE, RMSE, horizon-specific forecast error, uncertainty calibration/coverage, performance versus baseline models, and behavior as history length increases.
