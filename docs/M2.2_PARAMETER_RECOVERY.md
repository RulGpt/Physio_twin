# PHYSIO-TWIN M2.2 — Parameter Recovery Experiment

## Objective

M2.2 asks whether PHYSIO-TWIN parameters can be estimated from observations and inputs when the true hidden states and true parameters are withheld from the estimator.

The first estimator is intentionally restricted to the 14-parameter population observed-core model defined in M2.1.

## Estimator

The implementation uses `statsmodels.tsa.statespace.MLEModel`.

Statsmodels documents MLEModel as a state-space model for maximum-likelihood estimation. Its `fit()` method uses a numerical optimizer with the Kalman filter, while subclasses provide `start_params`, `update`, and parameter transformations where needed. citeturn0search2

The PHYSIO-TWIN estimator therefore has this separation:

- `synthetic.py`: creates ground truth
- `estimator.py`: sees only observations + inputs
- `experiment.py`: compares fitted parameters against withheld truth

## Parameterization

Free parameters:

### A

A00, A01, A10, A11

### B

B00, B01, B02
B10, B11, B12

### Q

Q00, Q11

### R

R00, R11

Total:

14 parameters.

Latent-load dynamics remain fixed during M2.2.

## Constraints

Noise variances are represented internally on the log scale and exponentiated during likelihood evaluation, guaranteeing positive diagonal variances.

Candidate transition matrices with spectral radius >= 0.995 are assigned a very poor likelihood.

The 0.995 threshold is an optimization safeguard for this experiment, not a biological constant.

## Metrics

### Parameter recovery

Relative RMSE is reported separately for:

- A observed core
- B observed rows
- Q observed diagonal
- R diagonal

### Predictive recovery

One-step observation RMSE is also measured.

This matters because parameter estimates can be imperfect while still producing useful predictions, or can look numerically plausible while forecasting poorly.

### Stability

The fitted spectral radius is reported.

## History-length experiment

M2.2 supports different longitudinal durations.

The first tests use:

- 60 days
- 100 days
- 180 days
- 240 days

The implementation does not assume that longer history automatically produces better estimates. That relationship must be measured.

## Scientific limitation

The synthetic generator and estimator use the same model family in this first parameter-recovery experiment.

Therefore M2.2 establishes:

- numerical estimability;
- optimizer behavior;
- parameter recovery under correct specification;
- sensitivity to history length.

It does not establish that the chosen model is correct for human physiology.

M1.3 already begins addressing model mismatch; later M2 experiments should combine mismatch with parameter estimation.

## Missing observations

The underlying statsmodels Kalman machinery supports missing observations through its state-space filtering architecture. M2.2's first parameter-recovery gate uses complete observations so that parameter recovery can be isolated from missingness. Missing-data parameter recovery should be a separate experiment.

## Decision gate

Do not proceed to full 23-parameter estimation merely because optimization converges.

Require:

1. finite and stable fitted parameters;
2. repeatability across seeds;
3. acceptable parameter recovery;
4. acceptable one-step predictive recovery;
5. sensitivity analysis across history length.

If parameter recovery is poor, investigate identifiability and scaling before adding model complexity.
