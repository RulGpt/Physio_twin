# PHYSIO-TWIN M1.3 — Model Robustness / Mismatch Experiment

## Why this milestone exists

M1.2 used a synthetic generator from the same broad linear state-space family as the estimator. That validates implementation, but it does not seriously test model assumptions.

M1.3 deliberately creates data that violate selected assumptions.

Model mismatch is a recognized issue in Kalman filtering: state estimation quality depends on the fidelity of the assumed dynamics and noise statistics. NASA literature specifically discusses degradation from erroneous system models and the limitations of linearization/nonlinear assumptions. citeturn0search2turn0search24

## Scenarios

### 1. Nonlinear saturation

Exercise response saturates instead of remaining linear, and stress/exercise interactions are added.

PHYSIO-TWIN still assumes:

`X(t+1) = A X(t) + B U(t) + w(t)`

Purpose: measure the cost of ignoring nonlinear input effects.

### 2. Delayed sleep effect

Sleep deficit influences the next day's state rather than only the current transition.

Purpose: test sensitivity to temporal-delay misspecification.

### 3. Correlated observation noise

Fatigue and recovery measurement errors have positive covariance.

PHYSIO-TWIN's baseline R matrix assumes diagonal measurement noise.

Purpose: test sensitivity to a misspecified observation covariance.

### 4. Person-specific dynamics

The synthetic person has different A and B parameters from the population model.

Purpose: demonstrate why personalization/parameter adaptation matters.

## Metrics

For each scenario:

- fatigue RMSE
- recovery RMSE
- load RMSE
- fatigue MAE
- recovery MAE
- load MAE
- mean normalized innovation

The innovation diagnostic is deliberately transparent. It is not treated as a formal likelihood or p-value.

## Interpretation

M1.3 does **not** have a requirement that the model "win" every scenario.

A scientifically useful result may be:

- robust under mild mismatch;
- degraded under delayed effects;
- substantially degraded under person-specific dynamics;
- systematically miscalibrated under correlated noise.

That information determines what needs to change in later model versions.

## Why we do not immediately replace the Kalman filter

A nonlinear generator does not automatically justify an EKF/UKF.

The classical Kalman filter is optimal under its linear/Gaussian assumptions. Nonlinear systems motivate extensions such as EKF/UKF, but those introduce additional assumptions and implementation complexity. citeturn0search24turn0search0

Therefore M1.3 first quantifies whether the linear model's failure is material.

## Next decision gate

After M1.3:

1. If errors remain acceptable under realistic mismatch, proceed to parameter estimation.
2. If delay effects dominate, add explicit lagged inputs.
3. If nonlinear saturation dominates, test a nonlinear model as a challenger.
4. If person-specific variation dominates, prioritize hierarchical/personal parameter estimation.
5. If noise misspecification dominates, estimate a full R matrix rather than forcing diagonal R.

No architectural change should be made merely because a more sophisticated filter exists.
