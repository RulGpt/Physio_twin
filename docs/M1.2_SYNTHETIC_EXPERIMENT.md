# PHYSIO-TWIN M1.2 — Synthetic Longitudinal Experiment

## Purpose

M1.2 tests whether the implemented state-space/Kalman model can recover known hidden states from noisy longitudinal observations.

This is a controlled mathematical validation experiment. It is **not evidence of clinical validity**.

## Data-generating process

For each synthetic day:

1. Generate routine inputs:
   - sleep deficit D
   - exercise load E
   - normalized stress S
2. Generate a hidden state using:
   `X_(t+1) = A X_t + B U_t + w_t`
3. Generate observations using:
   `Y_t = C X_t + v_t`
4. Randomly remove observations in selected experiments.
5. Give only inputs and observations to the filter.
6. Compare estimated states against the hidden ground truth.

The estimator never receives the hidden state.

## Experiments

### E1 — State recovery
Evaluate RMSE and MAE for:
- fatigue
- recovery
- latent load

The first part of the sequence is excluded from the primary accuracy summary to avoid overstating cold-start performance.

### E2 — Latent load
Load has no direct observation channel. The experiment checks whether coupling through A/B allows bounded reconstruction.

This is an identifiability experiment, not a claim that real physiological load can necessarily be identified from these two self-report signals.

### E3 — Missing observations
25% random observation missingness is introduced. The filter should continue operating.

When both observations are missing, the update becomes prediction-only.

### E4 — Uncertainty during missingness
A deliberately long missing-observation interval should increase covariance because process uncertainty accumulates without measurement correction.

When observations resume, covariance should decrease again.

### E5 — Forecasting
Evaluate short-horizon forecasts against future hidden states using known future inputs.

## What counts as success

Success in M1.2 means:

- the implementation is numerically stable;
- estimates remain finite;
- uncertainty behaves mathematically as expected;
- hidden states can be recovered under the synthetic data-generating assumptions;
- missing observations do not crash the filter;
- forecast errors are measurable and reproducible.

It does **not** mean that the model is validated for real humans.

## Important limitation

The synthetic generator currently uses the same structural state-space family as the estimator. Therefore M1.2 tests implementation correctness and recoverability under controlled assumptions, not model-form correctness for human physiology.

The next scientific step is therefore to introduce deliberately mismatched synthetic generators and then evaluate the model on real/research longitudinal data.
